# General

---

The system will eventually be hosted on the leo-cloud, our school's Quarkus solution so it needs to be dockerized and 
tested with minicube.

I'm expecting a maximum of 20 people accessing the website at a time, so a simple postgres db will do. It will store 
all events and keep track of the leaderboard. Those will be updated by uploading a gpx file or pasting a link to the 
activity from strava, komoot or other platforms.
